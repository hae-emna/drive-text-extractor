# Samples

`input/` is a small folder in which each file exercises one path of the pipeline. Use it in two ways:

- **Demo mode**: run the server with `FILE_SOURCE=local` and type `local:` as the link, or
  `local:<file name>` for a single file.
- **Google Drive**: the same files are in a public test folder,
  <https://drive.google.com/drive/folders/1HvFp6xojrjdTFNgeMda4QNCwMCHfKVef>, with `facture-francais.jpg` in a subfolder (tick *Include subfolders*). You can also
  upload them to your own folder shared as "Anyone with the link".

The files are generated by [`backend/scripts/make_samples.py`](../backend/scripts/make_samples.py).

| File | What it tests | Expected result |
|---|---|---|
| `invoice-native.pdf` | PDF with a text layer, French accents, 2 pages | `pdf_parser`, exact text |
| `contract-scanned.pdf` | Image-only PDF (a scan) | `ocr` |
| `report-mixed.pdf` | Typed page followed by a scanned annex | `mixed`: page 1 parsed, page 2 OCR'd |
| `receipt-english.png` | English image | `ocr` |
| `facture-francais.jpg` | French image (JPEG) | `ocr`, accents kept by RapidOCR; with Arabic also selected, Tesseract reads it and sometimes loses them (`à` → `a`) |
| `avis-arabe.png` | Arabic image, right-to-left | `ocr` with Arabic selected (Tesseract); it may miss a line (see README, *Known limits*). Without Arabic selected, the result is gibberish flagged as low confidence |
| `scan-rotated.jpg` | Page scanned sideways | straightened by orientation detection, then `ocr` |
| `corrupted.pdf` | Truncated PDF | `failed` with `corrupt_file`; the other files still finish |
| `notes.txt` | Unsupported type | listed as skipped with a reason, never sent to extraction |

## Exports

Both were produced by the app from the public test folder above.

- [`output-drive.json`](output-drive.json): every file, subfolders included, with English and
  French selected. Images go through RapidOCR; the Arabic notice comes out as noise flagged as low
  confidence, since Arabic was not selected.
- [`output-drive-arabic.json`](output-drive-arabic.json): `avis-arabe.png` alone, with Arabic
  selected (read by Tesseract).
